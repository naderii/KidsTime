# KidsTime — مرحله اول

پروژه پایه اندروید با Kotlin، Gradle Kotlin DSL و Jetpack Compose.

## امکانات موجود
- داشبورد اولیه کودک
- تنظیم سقف دقیقه‌ای برای هر روز هفته
- ذخیره محلی تنظیمات
- ورود پنل والدین با PIN آزمایشی `1234`
- تغییر PIN (هش SHA-256 ساده برای نمونه اولیه)
- افزودن و حذف دامنه‌های مجاز
- ثبت کلاس اولیه `VpnService` بدون فعال‌سازی تونل

## مواردی که هنوز پیاده‌سازی نشده‌اند
- پایش واقعی زمان استفاده با `UsageStatsManager`
- قفل دستگاه و Device Owner / Lock Task
- فیلتر واقعی بسته‌های شبکه یا DNS
- کنترل برنامه‌های مجاز
- جلوگیری از تغییر ساعت، Safe Mode، حذف برنامه یا دورزدن محدودیت
- حفظ و بازیابی سهمیه دقیق در همه حالت‌های خاموشی/راه‌اندازی مجدد

**این نسخه هنوز گوشی را قفل نمی‌کند و وب‌سایت‌ها را مسدود نمی‌کند.** فهرست سایت‌ها فقط ذخیره می‌شود.

## بازکردن پروژه
1. Android Studio را باز کنید.
2. گزینه **Open** را بزنید و پوشه `KidsTime` را انتخاب کنید.
3. اجازه دهید Gradle Sync انجام شود.
4. یک دستگاه یا شبیه‌ساز Android با API 26 یا بالاتر انتخاب کنید.
5. Run را بزنید.

پیش‌نیاز پیشنهادی: JDK 17 و Android SDK Platform 35. فایل Gradle Wrapper در این بسته قرار ندارد؛ Android Studio معمولاً می‌تواند پروژه را با نسخه Gradle سازگار تنظیم کند. اگر Sync خطای نسخه Gradle داد، از پیام خطا نسخه دقیق Gradle Wrapper را تنظیم کنید.

## تغییرات بعدی
1. افزودن UsageStatsManager و صفحه راهنمای فعال‌سازی Usage Access
2. مدل داده و ذخیره‌سازی پایدارتر (Room/DataStore)
3. پیاده‌سازی VPN DNS filtering با مدیریت مجوز و ترافیک واقعی
4. راه‌اندازی Device Owner و Lock Task روی دستگاه آزمایشی
5. تست امنیت، بازیابی پس از reboot و مسیر تماس اضطراری

## هشدار PIN (به‌روز شده)
رمز پیش‌فرض حذف شد؛ در اولین اجرا والد رمز می‌سازد (PBKDF2 + salt، قفل موقت پس از ۵ تلاش اشتباه). پنل با خروج از برنامه خودکار قفل می‌شود.

## هشدار قدیمی
PIN پیش‌فرض `1234` فقط برای نمونه اولیه است. پیش از استفاده واقعی حتماً باید حذف شود و احراز هویت والدین با طراحی امن‌تر جایگزین گردد.
